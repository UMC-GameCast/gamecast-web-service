# Subtitle Editor

자막 편집 및 생성 도구입니다.

## 주요 기능

### 1. 동영상 업로드
- MP4, WebM 등 다양한 형식 지원
- 드래그 앤 드롭으로 간편 업로드

### 2. 오디오 업로드 및 자막 생성

#### 단일 오디오 업로드
- 하나의 오디오 파일에서 자막 생성
- OpenAI Whisper API 사용
- 한국어 자동 인식

#### 다중 화자 오디오 업로드 (NEW!)
- 5명의 화자를 구분해서 자막 생성
- 각 화자별로 개별 오디오 파일 업로드
- 화자별 자막 자동 구분

**지원하는 화자:**
- 🔴 맥쥬 (maekju)
- 🟢 초록색매실 (choroksaengmaesil)
- 🟡 소정양주 (sojangyangju)
- 🟣 김모질 (kimmojil)
- 🔵 돔토로 (domtoro)

**사용법:**
1. "🎤 다중 화자" 버튼 클릭
2. 각 화자별로 오디오 파일 업로드
3. 개별 처리: 각 화자별로 따로 자막 생성
4. 전체 처리: 모든 업로드된 파일을 한번에 처리
5. 생성된 자막은 시간순으로 자동 정렬

### 3. 자막 편집
- 드래그로 시간 조정
- 리사이즈로 지속시간 변경
- 화자 및 감정 설정
- 실시간 미리보기

### 4. 자막 내보내기/가져오기
- SRT 형식 지원
- 기존 자막 파일 편집 가능

### 5. 렌더링
- FFmpeg 렌더링 (추천)
- Canvas 렌더링 (대안)
- 자막이 합성된 최종 동영상 생성

## 키보드 단축키

- `Space`: 재생/일시정지
- `Delete/Backspace`: 선택된 자막 삭제
- `Ctrl/Cmd + N`: 새 자막 추가
- `Ctrl/Cmd + S`: 자막 내보내기
- `Ctrl/Cmd + O`: 자막 가져오기
- `Escape`: 선택 해제
- `←/→`: 0.1초 단위로 시간 이동

## 기술 스택

- React + TypeScript
- OpenAI Whisper API
- FFmpeg.wasm
- Canvas API
- Tailwind CSS
